# التحقق من المرحلة الثانية

- `node tests/assessment.test.cjs`: 23 اختبارًا ناجحًا لمنطق التقييم.
- `node tests/pwa.test.cjs`: نجاح التثبيت البرمجي، الحزمة الكاملة، فشل تنزيل الصور واستئنافه، ونطاق المسار الفرعي.
- `python tests/content.test.py`: لا مراجع محلية مفقودة.
- `node tests/mobile.test.cjs` باستخدام Playwright وChromium: المقاسات 320×568، 360×800، 390×844، 800×1280، 1280×800، 1440×900. فحص الشاشة الرئيسية، الفهرس، القراءة، الخط الكبير مع الوضع الداكن، السؤال والتغذية الراجعة. تحقق من الحفظ والاستئناف والملاحظات والرسم، الأنواع الخمسة، النتائج والمراجعة، وإخفاء تصحيح الشامل أثناء المحاولة.
- تمت معاينة لقطتي شاشة الهاتف والتابلت بصريًا.

لا ادعاء باختبار أجهزة Samsung فعلية، أو تثبيت Android يدوي، أو سلامة أكاديمية نهائية للمنهج. بيانات المرحلة الأولى وحدود تغطيتها لم تتغير. يحتفظ المشروع بالنسخة السابقة ومساراتها.

- تحقق متصفح فعلي من تنزيل الحزمة عبر Service Worker، فصل الشبكة، إعادة تحميل التطبيق وبدء امتحان بلا اتصال.
- تحقق من بقاء مسودة الإجابة غير المؤكدة بعد إعادة التحميل.
