# تدقيق الهوية ونظام التصميم

## الهوية الأصلية المحفوظة

| الرمز | القيمة الأصلية | الاستخدام |
|---|---|---|
| `--brand` | `#2d6a68` | اللون الأخضر المزرق الأساسي |
| `--brand-dark` | `#1f4f4d` | نصوص/تفاصيل قوية |
| `--brand-soft` | `#e4f1ef` | أسطح هادئة |
| `--accent` | `#c98b5c` | لمسة دافئة وتلميحات |
| `--bg` | `#f3f7f6` | الخلفية |
| `--ink` | `#172826` | النص |
| `--muted` | `#667773` | النص الثانوي |
| `--line` | `#dbe7e3` | الحدود |
| `--radius-xl/lg/md` | `28/20/14px` | البطاقات والأزرار |
| `--shadow-soft` | `0 8px 28px rgba(29,67,63,.08)` | عمق خفيف |

الخط Cairo مع Tahoma/Arial بديلًا؛ بقي شعار السن، والأخضر، والبطاقات المستديرة، والتدرجات الهادئة، وRTL على مستوى المستند. أضيفت ملفات خط محلية بأوزان 400/600/700/800 مع رخصة OFL، وأزيل اعتماد صفحات HTML على Google Fonts.

## الصقل

المسافات الجديدة 6/12/18/24/32 بكسل؛ هدف لمس 48 بكسل؛ النص الأساسي 16 بكسل دون تصغير لمنع التمرير. التخطيط يبدأ من الهاتف، ويستخدم `100dvh` في الجلسة، وصفًا مركزيًا قابلًا للتمرير، وتذييلًا منفصلًا ثابت الموضع في شبكة الصفحة. مراعاة `safe-area-inset-*`، وحد أقصى مناسب للقراءة على سطح المكتب، وعناصر input بحجم 16 لتجنب التكبير التلقائي في الأجهزة المعتادة.

بعد الإجابة، تتحول الخيارات إلى ملخص الإجابة مع التفسير، لتقليل التمرير. النص الطويل يظل كاملًا ولا يقطع. الترتيب يتم بأزرار رفع/خفض بدل الاعتماد على السحب، والمطابقة بقوائم ذات تسميات. يدعم التركيز الظاهر، لوحة المفاتيح، `aria-pressed`، ومنطقة حالة للتغذية الراجعة.

حركة شريط التقدم 160ms فقط، واحترام `prefers-reduced-motion`. لا confetti ولا bounce. الوضع الداكن يرث لوحة الألوان الأصلية؛ النص فوق الزر الفاتح في الوضع الداكن أصبح داكنًا لتحسين التباين.

## ما لم يُدّع اختباره

فحوص الهاتف محاكاة أبعاد في Chromium، وليست أجهزة iOS/Android فعلية. لوحة المفاتيح البرمجية وSafe Areas في أجهزة حقيقية تحتاج فحصًا ميدانيًا. لم نغيّر تصميم كل صفحة مرجعية؛ أضيف التكامل والتصحيحات للطبقة الحالية.
