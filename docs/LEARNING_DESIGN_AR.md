# تصميم التعلم والتقييم

## دورة التعلم

تعلم قصير للمفهوم الجديد أو المتعثر ← محاولة استرجاع قبل كشف الجواب ← سؤال موضوعي ← تفسير وسبب قرار المراجعة ← تطبيق/تمييز إضافي بحسب الوضع ← سؤال بديل عند الخطأ ← مراجعة مستقبلية.

الدرس المرجعي الطويل يبقى متاحًا. داخل الجلسة تظهر فكرة أو مهمة واحدة مع إجراء أساسي ثابت. لا يجبر الطالب على إدخال إجابة نصية للاسترجاع الحر؛ يمكنه التفكير ثم تقييم استرجاعه، لكن هذه الإجابة الذاتية لا تُعد إثبات إتقان.

## النموذج الأولي

اختيرت بنية الأسنان (PDF 17–19): خمسة مفاهيم و23 سؤالًا قبل التوسع. اختُبرت القراءة والاسترجاع والخطأ والتغذية الراجعة وإعادة التحميل والاستئناف. بعد نجاح النموذج توسع البنك إلى الوحدات الـ17. شملت الأنواع: الاسترجاع الحر، الاختيار، صح/خطأ، ملء الفراغ، المطابقة والترتيب. لا صور تشخيصية أو سيناريوهات علاجية مولدة؛ الصور التشريحية الأصلية باقية بالمرجع.

## جودة الأسئلة

صيغت الأسئلة الجديدة يدويًا من مقاطع المقرر، مع فصل prompt وcorrectAnswer وexplanation وhint والمصدر. عُدلت صيغ الاسترجاع لتختلف عن أسئلة الاختيار، وخُفض تصنيف الأسئلة التي لا تتجاوز مطابقة الوصف إلى «فهم» بدل تسميتها تطبيقًا سريريًا. الخيارات تُخلط مرة واحدة وتُحفظ طوال الجلسة. التلميح مساعدة مسجلة؛ لا يُحسب استعماله نجاحًا مستقلًا.

السيناريوهات الجديدة تعليمية قصيرة، مثل التمييز بين العاج الثانوي والثالثي أو مقارنة أثر مدة تناول السكر. الأسئلة التي تطلب مجرد تسمية من وصف ليست محاكاة تشخيصية ولا اختبار كفاءة سريرية. صياغة الخيار الخاطئ تمثل احتمالًا للاختبار، وليست معلومة طبية مقررة.

## الأوضاع

| الوضع | السلوك |
|---|---|
| مراجعة اليوم | أولوية للأخطاء، ثم المستحق، ثم الجديد؛ حتى 5 مفاهيم |
| سريع | حتى 3 مفاهيم، أسئلة موضوعية دون بطاقات استرجاع إضافية |
| قياسي | حتى 5 مفاهيم، استرجاع وممارسة وسؤال إضافي إن توفر |
| معمق | حتى 8 مفاهيم، تغطية أوسع وسؤال إضافي |
| نقاط الضعف | مفاهيم سبق تدريبها وحالتها ضعيفة/قيد التعلم |
| أخطائي | مفاهيم لها أخطاء لم تثبت بعد |
| تحدي الوحدة | أسئلة موضوعية؛ لا بطاقات تقييم ذاتي |
| الاختبار الشامل | صفحة الاختبار الأصلية، مستقلة عن قياس الإتقان الجديد |

تقدير الزمن تقريبي، لا مؤقت ملزم. لا تدخل مدة التردد وحدها في العقوبة؛ قد تعكس القراءة أو الإعاقة أو التشتت. تخزن latency المحدودة للتحليل، ويؤثر تصريح الطالب «متردد» في الجدولة.

## الإتقان والتحفيز

لا نقاط لمجرد فتح درس، ولا XP ينافس هدف التعلم. التحفيز بعرض المراجعات المنجزة ودليل الإتقان وموعد المراجعة. النجاح في الجلسة لا يساوي الاحتفاظ طويل الأمد. معيار الإتقان تشغيلي قابل للتفسير وليس احتمالًا إحصائيًا معايرًا؛ يحتاج تقييمًا تجريبيًا مع طلاب ومختصين قبل أي ادعاء فعالية تعليمية مقاسة.
