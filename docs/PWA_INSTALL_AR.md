# التثبيت والعمل دون إنترنت

- افتح الموقع عبر HTTPS في Chrome على Android، واضغط «ثبّت التطبيق». عند عدم توفر نافذة التثبيت يعرض الزر تعليمات قائمة المتصفح.
- iPhone: Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.
- من الرئيسية اضغط «حفظ الدروس دون إنترنت» وانتظر «جاهز دون إنترنت». يُحفظ نحو 8.2 ميغابايت تتضمن الدروس والصور والخطوط والبنك القديم والبنك المتكيّف. ملف PDF المصدر والتقارير غير مشمولة بالحفظ المسبق.
- تقدم التعلم يبقى محليًا؛ تثبيت التطبيق لا ينشئ حسابًا أو مزامنة. مسح بيانات المتصفح قد يحذف التقدم والمحتوى المحفوظ.
- التحديثات تستخدم مخزنًا مستقلًا لكل إصدار. عند ظهور «تحديث التطبيق»، ارجع للرئيسية واضغطه؛ ثم أعد حفظ الدروس إذا طلبت الواجهة ذلك. لا يُحذف localStorage أثناء التحديث.
- نطاق التطبيق نسبي ومتوافق مع /Dental/ في GitHub Pages، ولا يحذف مخازن المواقع الأخرى.

## التحقق
نجحت اختبارات بيانات المحتوى ومحرك التدريب (18 اختبارًا)، وفحص 842 مرجعًا محليًا.
نجح اختبار عامل الخدمة لفشل التنزيل واستئنافه واكتماله، وروابط الدروس ذات المعاملات، وحدود النطاق، وتوفر بنكي الأسئلة دون اتصال.
نجحت تجربة Chromium فعلية بعرض 360 بكسل: إرشادات التثبيت، التنزيل، إعادة التحميل دون إنترنت، جلسة تدريب، فتح درس بمعاملاته، بلا أخطاء JavaScript أو تمرير أفقي.
تأكيد نافذة التثبيت الأصلية على Android وiOS يحتاج تجربة فعلية على الهاتف؛ المتصفح الآلي اختبر التعليمات والحفظ دون اتصال.
