# Oral Health Learning Path 1.2

تطوير للمشروع الأصلي، مع الحفاظ على هويته العربية ومساره. ابدأ من `index.html` ثم «ابدأ مراجعة اليوم». التدريب الجديد في `adaptive.html`؛ المسار والمرجع والاختبار القديم ما زالت متاحة.

## التشغيل

1. فك الضغط كاملًا؛ لا تفتح HTML من داخل ZIP.
2. افتح `site/index.html` في متصفح حديث. لا توجد عملية Build ولا API keys.
3. يفضّل خادم محلي لتوحيد حفظ البيانات وسلوك الروابط:

```bash
cd site
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. الملفات والخط والصور وPDF محلية. رابط المصدر الخارجي يحتاج الإنترنت فقط عند فتحه. التشغيل المحلي دون الإنترنت متاح، لكنه ليس PWA مثبتة ولا يضمن تخزين موقع منشور في الكاش بعد إغلاقه.

## التجربة المقترحة

- افتح مراجعة اليوم، أو اختر «بنية الأسنان» ← تدريب قياسي.
- حاول الاسترجاع، اكشف الإجابة، ثم أجب السؤال الموضوعي.
- جرب إجابة خاطئة وتلميحًا لترى اختلاف التغذية الراجعة والموعد.
- استخدم حفظ وخروج ثم متابعة الجلسة؛ أعد تحميل الصفحة للتأكد من الاستئناف.
- من «بياناتي» صدّر التقدم قبل مسح المتصفح أو تغيير الجهاز.

## ما الذي أضيف؟

54 مفهومًا و173 سؤالًا جديدًا مرتبطًا بالمفاهيم الأساسية لجميع الدروس الـ93. استرجاع وMCQ وصح/خطأ وفراغ وترتيب ومطابقة، مراجعة متباعدة، تتبع الأخطاء، ست حالات إتقان، واختيار يتغير وفق الأداء. لا تُحتسب قراءة الدرس إتقانًا.

المقرر 70 صفحة PDF؛ لا تخلط بينها وبين صفحات الموقع الـ17. حالة `source-checked` تعني مطابقة تعليمية للمصدر، وليست اعتمادًا من مختص. يوجد تصحيح خارجي معلن لخريطة الذوق. راجع `docs/SCIENTIFIC_REVIEW_AR.md` قبل اعتماد المحتوى أكاديميًا؛ لم يُعتمد البنك القديم كله طبيًا.

## النشر

ارفع **محتويات مجلد site** إلى أي استضافة ملفات ثابتة تدعم HTTPS؛ حافظ على المسارات وحالة الأحرف. اجعل `index.html` الصفحة الافتراضية. لا ترفع نسخة الاحتياط الخاصة بالمصدر إلى موقع عام دون حاجة. لم تُنشر هذه الحزمة تلقائيًا إلى موقع عام.

تقدم الطالب مرتبط بالمتصفح والأصل (origin). استخدم نفس عنوان النشر لاستمرار البيانات. لا تعِد تسمية مفاتيح التخزين ولا تعتبر نتائج المسار القديم أدلة إتقان جديدة. لا يوجد إرسال للتقدم إلى خادم.

## التعديل والتحقق

حرر `data/adaptive-bank.json` ثم:

```bash
python3 scripts/sync-bank.py
node tests/engine.test.cjs
python3 tests/content.test.py
```

اختبار المتصفح يحتاج Node وPlaywright وChromium. من المجلد الأب الذي يحتوي `site/`:

```bash
CHROMIUM_PATH=/path/to/chromium node site/tests/browser.test.cjs
```

اختبار المتصفح ينشئ خادمًا مؤقتًا على المنفذ 8013 ويغلقه بعد الانتهاء. لا يحتاج Playwright للتشغيل العادي؛ هو اعتماد تطوير فقط. الصور والنتائج في `qa/` عند الاختبار.
